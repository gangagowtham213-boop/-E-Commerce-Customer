E-COMMERCE CUSTOMER BEHAVIOUR & SALES ANALYTICS

IMPORTANT DATASET NOTE
The ZIP includes a small authentic sample preview and a downloader script, not the full 541,909-row dataset.
Run data/download_dataset.py to fetch the full official UCI Online Retail dataset (requires internet).
The official dataset is UCI ID 352, DOI 10.24432/C5BW33, CC BY 4.0.

Folders:
data/       dataset downloader + small authentic sample
python/     data cleaning, EDA and RFM segmentation
pyspark/    distributed ETL
hive/       Hive DDL and analysis queries
mapreduce/  Hadoop Streaming mapper/reducer
mongodb/    MongoDB loader
cassandra/  Cassandra schema and loader
powerbi/    DAX measures, dashboard guide and sample preview
docs/       project report and presentation

Start with RUN_ME_FIRST.txt.
Hadoop/Hive/Spark/MongoDB/Cassandra servers must be installed separately.
